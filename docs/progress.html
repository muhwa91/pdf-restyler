H SECURITY 명함 생성 프로그램 완성 완료

2026-06-28 · 담당: 메인

📌 요청 — 디자인 명함(PDF)의 글자·색을 바꿔 직원 명함을 만들고 싶다. 비개발자 친구도 쓸 수 있게 프로그램으로 만들어줘.

✅ 처리 — 이름·연락처를 입력하면 명함 PDF가 자동으로 만들어지는 Windows 프로그램을 완성했습니다. 대표(핑크)·직원(검정) 디자인, 입력 즉시 미리보기, 한 번에 PDF 저장. 다크 테마(indigo 포인트)·치이카와 아이콘을 입히고, 더블클릭으로 실행되는 exe·사용설명서·배포용 zip까지 만들었습니다.

명함 편집 방식 검증 (PoC) 완료

2026-06-28 · 담당: 메인

📌 요청 — 명함 템플릿의 글자(이름·연락처)와 색을 실제로 바꿀 수 있는지 먼저 확인해줘.

✅ 처리 — 명함 글자가 그림(곡선)으로 박혀 있어 그대로는 못 바꾸지만, 같은 위치·색·폰트(Pretendard)로 다시 그려 교체할 수 있음을 확인했습니다. 개인정보가 PDF에 남지 않도록 실제 삭제(redaction) 방식도 적용했습니다.
